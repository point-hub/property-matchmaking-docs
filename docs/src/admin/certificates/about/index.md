# Certificates

Manage property certificates and related legal documents available on the platform. Administrators can create, view, update, and delete certificate records to ensure that each property has complete and accurate ownership documentation.

## Features

| Feature | Description |
| ------- | ----------- |
| [Create Certificate](/admin/certificates/create/) | Allows users to create a new certificate. |
| [List Certificates](/admin/certificates/list/) | Displays all available certificate listings with filtering and sorting options. |
| [Read Certificate](/admin/certificates/read/) | Displays detailed information about a specific certificate. |
| [Update Certificate](/admin/certificates/update/) | Allows users to modify an existing certificate listing. |
| [Delete Certificate](/admin/certificates/delete/) | Allows users to permanently remove a certificate listing. |
