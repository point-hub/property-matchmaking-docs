# Create Facility

Allows users to create a new facility by entering the required information and supporting details.

## Scenarios

- **Success Scenarios**
  - [1.3.1.S1. User can create facility successfully.](/admin/facilities/create/scenarios/s1/)
- **Failure Scenarios**
  - [1.3.1.F1. Create facility fails when user is not authenticated.](/admin/facilities/create/scenarios/f1/)
  - [1.3.1.F2. Create facility fails when required fields are empty.](/admin/facilities/create/scenarios/f2/)
