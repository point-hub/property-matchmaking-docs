# Problems

Manage property problems and related legal documents available on the platform. Administrators can create, view, update, and delete problem records to ensure that each property has complete and accurate ownership documentation.

## Features

| Feature | Description |
| ------- | ----------- |
| [Create Problem](/admin/problems/create/) | Allows users to create a new problem. |
| [List Problems](/admin/problems/list/) | Displays all available problem listings with filtering and sorting options. |
| [Read Problem](/admin/problems/read/) | Displays detailed information about a specific problem. |
| [Update Problem](/admin/problems/update/) | Allows users to modify an existing problem listing. |
| [Delete Problem](/admin/problems/delete/) | Allows users to permanently remove a problem listing. |
