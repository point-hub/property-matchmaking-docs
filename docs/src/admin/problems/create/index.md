# Create Problem

Allows users to create a new problem by entering the required information and supporting details.

## Scenarios

- **Success Scenarios**
  - [1.3.1.S1. User can create problem successfully.](/admin/problems/create/scenarios/s1/)
- **Failure Scenarios**
  - [1.3.1.F1. Create problem fails when user is not authenticated.](/admin/problems/create/scenarios/f1/)
  - [1.3.1.F2. Create problem fails when required fields are empty.](/admin/problems/create/scenarios/f2/)
