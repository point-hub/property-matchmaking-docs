# ADR#006

## Topic

Rename the "Contact via WhatsApp" call-to-action to "Dapatkan hasil rekomendasi".

## Problem

The "Contact via WhatsApp" label focuses on the communication channel rather than the user's goal.

Users complete the property recommendation process because they want to receive their property recommendations. The existing label may therefore make the purpose of the action unclear.

## Decision

Rename "Contact via WhatsApp" to "Dapatkan hasil rekomendasi"

## Reason

The phrase "Dapatkan hasil rekomendasi" is more aligned with the user's goal of receiving property recommendations rather than simply contacting the business through WhatsApp.
