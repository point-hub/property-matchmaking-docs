# Land Titles

Manage property land titles and related legal documents available on the platform. Administrators can create, view, update, and delete land title records to ensure that each property has complete and accurate ownership documentation.

## Features

| Feature | Description |
| ------- | ----------- |
| [Create Land Title](./create/) | Allows users to create a new land title. |
| [List Land Titles](./list/) | Displays all available land title listings with filtering and sorting options. |
| [Read Land Title](./read/) | Displays detailed information about a specific land title. |
| [Update Land Title](./update/) | Allows users to modify an existing land title listing. |
| [Delete Land Title](./delete/) | Allows users to permanently remove a land title listing. |
