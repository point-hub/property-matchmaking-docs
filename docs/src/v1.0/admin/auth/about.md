# Auth

The Auth handles all user authentication and access control for the application. It ensures that only registered and verified users can access the system while providing mechanisms for account creation, password recovery, and secure login/logout.

## Features

| Feature | Description |
| ------- | ----------- |
| [Signup](./signup/)                               | Allows new users to create an account using email and password.                              |
| [Verify Email](./verify-email/)                   | Sends a verification email to confirm the user’s email address.                              |
| [Signin](./signin/)                               | Enables registered users to log in to the application.                                       |
| [Signout](./signout/)                             | Allows users to securely log out of the application.                                         |
| [Forgot Password](./forgot-password/)             | Provides a way for users to request a password reset link if they forget their password.     |
| [Reset Password](./reset-password/)               | Allows users to set a new password after verifying their identity.                           |
