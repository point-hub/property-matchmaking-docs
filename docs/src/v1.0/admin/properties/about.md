# Properties

Manage property listings available on the platform, including property details, location, pricing, facilities, land titles, promotional offers, and other relevant information. This data serves as the primary source for generating personalized property recommendations for customers.

## Features

| Feature | Description |
| ------- | ----------- |
| [Create Property](./create/) | Allows users to create a new property. |
| [List Properties](./list/) | Displays all available property listings with filtering and sorting options. |
| [Read Property](./read/) | Displays detailed information about a specific property. |
| [Update Property](./update/) | Allows users to modify an existing property listing. |
| [Delete Property](./delete/) | Allows users to permanently remove a property listing. |
